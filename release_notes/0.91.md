Search by in-game name, follow records to their placed references, base records and list entries, and a settings file.

## New

- **Search by in-game name:** `wp name:"iron sword"` or `wp name~"^Daedric"`. Works without powerofthree's Tweaks, because names are always kept. A reference matches by its base record's name.
- **Placed references:** `wp refs:IronSword` lists the references placed from a record, by form ID or editor ID. Only references in memory can be found: the loaded cells and persistent references.
- **Base records:** `wp base:00000014` gives the record a reference was placed from (00000014 is the player, whose base record is 00000007).
- **List contents:** `wp contents:LItemWeaponSword` lists what a leveled list or form list holds, including nested lists and their entries, and forms that scripts added to form lists.
- **More detail for references:** looking up a reference shows its base record, its cell and its position, and whether it's disabled.
- All three combine with the other fields, for example `wp contents:LItemWeaponSword && plugin-name:dawnguard`.
- **Settings file:** `Data\SKSE\Plugins\WhichPlugin.ini` sets the short command name (if another mod uses `wp`), how many lines the console shows, the default layout, the log level and what `wp` may open or write.
- **Open things from the console:** `wp open` opens the output folder and `wp open last` the last file written. `wp help --web` opens this help on GitHub, `wp uesp WEAP` UESP's page on a record type (or the type of a form ID), and `wp json` a JSON checker.
- **Safer output:** files can only be text types (.txt .csv .tsv .log .md .ini .toml .xml .yaml .yml .json). With `bOverwriteNeedsConfirm = 1`, `>` won't replace an existing file and `>!` does.
- **Variables:** `wp export NAME=value`, `wp unset NAME` and `wp env`, then `$NAME` anywhere in a line, for example `wp base:$SELECTED`. `$(wp -c ...)` puts a command's output into the line. Built in: `$SELECTED` (the console's selected reference), `$CROSSHAIR`, `$PLAYER`, `$CELL`, `$WORLDSPACE`, `$LAST_RECORD`, `$LAST_FILE`, `$LAST_OUTPUT` and `$CLIPBOARD`. Your variables are kept between games in `My Games\Skyrim Special Edition\wp\vars.json`.
- **Text tools after a pipe:** `grep`, `sed`, `sort`, `uniq`, `head`, `tail`, `wc`, `echo` and `cat`, with their usual options, for example `wp -c type=WEAP && name:sword | sort | head -5`. A pipe sees every result, not only the ones the console shows.

## Upgrading

- Files written with `> name` now go to `Documents\My Games\Skyrim Special Edition\wp`, not straight into `Skyrim Special Edition`. Set `bWriteFileAnywhere = 1` to write elsewhere with a full path.
- To search for a plugin named after an action (open, json, uesp), quote it: `wp "open"`.
