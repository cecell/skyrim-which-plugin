First release: find loaded plugins, load-order slots and records from Skyrim's console with one command, `wp`.

## New

- **Plugin search:** `wp` lists every loaded plugin. `wp patch` finds plugins by name or by load-order slot.
- **Form ID lookup:** `wp 00012EB7` shows which plugin owns a form, its master, the last plugin to edit it and its editor ID.
- **Record search:** search by form ID, editor ID, record type or keyword, then narrow the results by plugin.
- **Three ways to match:** contains (`:`), exact (`=`) and regex (`~`).
- **Combine searches:** `&&`, `||` and `!`, for example `wp "cc" && !"esl"`.
- **Output options:** IDs only (`-c`), one aligned row each (`-d`), load-order-independent IDs (`-l`) and decimal IDs (`--int`).
- **Save the results:** `> name` writes a file in your My Games folder, `>> name` appends to one and `>>>` copies to the clipboard.
- **Works in bat files,** and alongside Console Command Extender.

## Known limits

- Searching by editor ID needs powerofthree's Tweaks for most record types, because the game discards most editor IDs when it loads.
- Text tools after a pipe (`| grep` and others) aren't built yet.
- Only tested on Skyrim 1.6.1170.
